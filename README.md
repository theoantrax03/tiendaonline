# TiendaOnline

Proyecto individual de Mateo Amangano · Aprendizaje Autónomo 1 · Programación Orientada a Objetos 1 · UIDE.

## Etapa 1 · Planeación del software

TiendaOnline se plantea como un sistema de gestión de comercio electrónico para una tienda pequeña. El objetivo es centralizar las cuentas de clientes y la administración de productos.

- **M1 · Gestión de Usuarios.** Registro, validación de correo único e inicio de sesión.
- **M2 · Catálogo de Productos.** Consulta, búsqueda y filtros. Creación, edición y desactivación por el administrador.

El carrito, los pedidos, los pagos y los envíos quedan proyectados. El diseño prevé Go como lenguaje y GoLand como entorno, con funciones puras para las reglas del negocio y copias de las colecciones al actualizarlas. Se contemplan paquetes de la biblioteca estándar de Go.
