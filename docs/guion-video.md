Hola, soy Mateo Amangano. Para el Aprendizaje Autónomo 1 elegí TiendaOnline, un sistema de gestión de comercio electrónico para una tienda pequeña. El trabajo es individual. Esta primera etapa consiste en planear el sistema y preparar el repositorio para el desarrollo.

[Muestra la tabla de módulos.]

El objetivo es gestionar las cuentas de los clientes y mantener actualizado el catálogo. El módulo de usuarios contempla el registro y el inicio de sesión. Cada correo podrá pertenecer a una sola cuenta. El módulo de catálogo permitirá buscar productos y filtrarlos por categoría. El administrador podrá agregar, editar o desactivar productos. Por ejemplo, una camisa Oxford desactivada dejará de aparecer en la búsqueda pública. El carrito, los pedidos, los pagos y los envíos quedan como posibilidades para etapas posteriores.

[Muestra la sección de programación funcional y paquetes.]

El código se desarrollará en Go y se trabajará en GoLand. Para aplicar programación funcional, las reglas recibirán datos y devolverán resultados. Por ejemplo, al desactivar un producto se generará una lista nueva con el cambio. Para buscar productos, primero se filtrarán los activos y luego se aplicarán la búsqueda y la categoría. Se prevé usar paquetes de la biblioteca estándar de Go, como strings para las búsquedas y testing para las futuras pruebas.

[Muestra el README y la carpeta docs de GitHub.]

El repositorio reúne la planeación y explica el alcance. En el Autónomo 2 comenzará la implementación. Las tareas concretas de los Autónomos 3 y 4 se ajustarán a las consignas del docente, con la meta de completar e integrar el sistema en el cuarto. Gracias.
